# 2W

macOS 原生 RSS 阅读器。外文文章逐段对照母语，论坛帖子连回帖一起读，数据全部留在本机。

![macOS 15+](https://img.shields.io/badge/macOS-15%2B-black) ![Universal](https://img.shields.io/badge/binary-universal-black) ![SwiftUI](https://img.shields.io/badge/SwiftUI-%2B%20GRDB-black)

## 起因

我自己每天用的那个阅读器做得实在不好：不开源，出了问题只能干等；界面和抓取一堆毛病；而且塞了一大堆 AI 功能——AI 雷达、AI 摘要、AI 追问，全是我不需要的，还占着最显眼的位置。我真正想要的只有一件事：**外文文章能逐段对照着读**。

所以自己写了一个。只做阅读器该做的事，代码公开，谁都能改。

## 这个应用做什么

### 双语对照

- 按 `T` 逐段插入译文，代码块自动跳过，原文与译文上下对照
- 两个翻译引擎：**系统翻译**（macOS 15 自带，离线、免费、不需要任何 key）或 **任意 OpenAI 兼容 API**（自己填 Base URL 和模型，key 存本机钥匙串）
- 译文按「段落 + 引擎 + 原文哈希」缓存，原文没变就不重复翻；换引擎不会吃到另一个引擎的旧译文
- 目标语言可选简体中文 / 繁體中文 / English / 日本語；和目标语言同族的文章不显示翻译按钮
- 外文文章可设为自动进入对照模式

### 论坛帖子连回帖一起读

RSS 读论坛只给一个标题等于没读。2W 把回帖抓下来直接渲染在正文后面，楼层可以一起翻译：

- **V2EX**（官方 API）、**Hacker News**（Algolia，嵌套评论树）
- **Reddit**（评论树 + RSS 正文重排）
- **所有 Discourse 站点**——按引擎识别而不是域名白名单，`linux.do`、Rust/Swift 官方论坛这类站开箱即用；认错了会静默降级成普通文章，不打扰你
- **Lobsters**
- 「刷新回帖」原地更新楼层，阅读位置不动

### 订阅与抓取

- RSS / Atom / JSON Feed；贴网页地址自动发现 feed，页面有多个就列出来让你挑，一个都没声明就探测常见路径
- YouTube 频道页或 `@handle` 直接贴进来就能订阅，可按源过滤 Shorts
- 同域名串行抓取、跨域并发，遵守 `Retry-After`
- 403/429 只暂缓不判死刑，404/410 才停自动重试并标红
- 条件请求（ETag / If-Modified-Since）+ 正文指纹，内容没变不重复解析
- 每个源可单独设 User-Agent、刷新间隔、HTTP Basic 凭据
- 源死了可以「查找新地址」一键换址，历史文章保留
- 拖拽整理分组，OPML 导入导出

### 让信息量可控

- **静音规则**：包含或正则 × 标题/正文/作者/URL/分类 × 全局/分组/单源 × 隐藏/标已读/折叠，可加例外词。保存后立即回扫全部历史并告诉你命中多少篇；误伤的可以在「已静音」里放行
- **跨源去重**：不同订阅的同一篇文章在聚合视图里只出现一次，标注来源数。只认规范化 URL（去跟踪参数），不靠标题相似度猜
- **未读徽标可按源或按分组关闭**，高频源不再淹没未读总数
- **保留策略**可全局设也可按源覆盖，星标永久保留
- **源健康面板**：每个源近 30 天来了多少、你读了多少、被静音多少，按最不看的排在最前面，可批量退订

### 阅读

- 三栏布局 + 沉浸模式，全键盘操作（`j`/`k`/`↩`/`⌘↩`/`Space`/`m`/`s`/`T`，键位可改）
- 摘要源自动抓全文，可按源设「自动 / 总是 / 从不」并指定 CSS 选择器；失败给「重试 / 浏览器打开 / 此源从不抓取」三个出口
- 「打开即已读」和「滚动到底已读」是两个独立开关；列表右键可「这篇及以下标为已读」，手滑了有撤销
- 记住每篇的阅读位置，纸面排版，字号可调，浅色/深色主题
- 疑似付费墙的站点在列表里标出来，点进去之前就知道
- 单篇网页可以直接保存进来（⌘⇧N），和订阅内容一起搜索、导出

### 搜索与数据

- 全文搜索**包含正文**，中英文都能搜
- 搜索可限定范围（当前范围 / 全部订阅）和时间（7 天 / 30 天 / 一年），并保存成侧栏的智能源
- 一致性快照备份，运行中就能备份；恢复前校验版本，旧库自动留一份 `.bak`
- 订阅列表每天自动备份 OPML，保留最近 7 份
- 单篇导出 Markdown（含译文与楼层）
- **没有账号，没有云端，没有遥测。** 所有数据在 `~/Library/Application Support/BiFeed/`

## 不做什么

- 不做 AI 摘要、AI 推荐、AI 追问。翻译是唯一用到模型的地方，而且可以完全离线
- 不做云同步账号
- 不做内置播客播放器
- 不绕过付费墙——只是提前告诉你哪些站需要订阅

## 安装

下载 `2W.dmg`，拖进「应用程序」。

首次打开会被 Gatekeeper 拦住（应用是 ad-hoc 签名，没有 99 美元开发者证书）：**系统设置 → 隐私与安全性 → 仍要打开**。

系统要求 **macOS 15 或更高**（逐段翻译用的是系统 Translation 框架）。二进制是 **universal**，Apple Silicon 和 Intel 都原生运行。

## 自己构建

```bash
git clone https://github.com/cbl-github/2W.git
cd 2W
./build.sh --universal        # 产物 dist/2W.app
scripts/make-dmg.sh           # 产物 dist/2W.dmg
```

只编当前架构的话 `./build.sh` 就够，纯 Command Line Tools 即可；`--universal` 需要完整 Xcode（通用二进制走 XCBuild）。

跑测试需要 Xcode 的 XCTest：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

## 技术

SwiftUI + GRDB（SQLite）+ FeedKit + WKWebView，Swift Package Manager 构建，无 Xcode 工程文件。

两个关键设计：文章元数据与正文分表存储，列表查询永不触碰大字段；整个阅读器复用单个 `WKWebView` 实例，切换文章只换内容不重建视图。

> Swift 模块名不能以数字开头，所以仓库里的 target 仍叫 `BiFeed`——那是这个项目的旧名字，产物和界面都是 2W。
